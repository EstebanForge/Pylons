# Conventions

This folder holds cross-project engineering patterns and closed vocabularies (including `vocabulary.md`).

## Rules

- Draft new conventions in `proposals/` from `../templates/convention.md` (`status: proposed`).
- Move accepted or enforced conventions to this folder root.
- Move replaced conventions to `archive/` with `status: superseded`.
