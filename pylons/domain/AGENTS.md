# Domain

This folder holds the shared ubiquitous language and entity definitions under `entities/`.

## Rules

- Scaffold entity definitions in `entities/<slug>.md` from `../templates/domain-entity.md`.
- Allowed `status:` values: `proposed`, `accepted`, `changed`.
- Link domain terms when referenced in other documents (`PYLON005`).
