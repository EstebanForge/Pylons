# Proposals

This folder holds draft plans under review (`status: proposed`).

## Rules

- Scaffold from `../templates/plan.md`.
- Name files `<type>-<slug>.md` where `<type>` is `feature`, `refactor`, `chore`, `docs`, or `perf` (`PYLON038`).
- Never place bug fixes here; route complex bugs to `../investigations/`.
- Once accepted, update `status: accepted` and move the file to `../plans/`.
